# weather-sih

VARSHAAI — Regime-Aware AI Rainfall Forecast Post-Processing (Smart India Hackathon SIH 26080)

## Overview
VARSHAAI is an intelligent weather forecast post-processing system providing bias correction, extreme event detection, and real-time visualization for meteorological forecasting.

## Getting Started
1. Run `start_website.bat` or `python run_server.py` to start the backend and launch the frontend.
2. Open `index.html` in your browser.
